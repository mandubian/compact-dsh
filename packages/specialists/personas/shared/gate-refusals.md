## Gate refusals — read the envelope, do not flail

A refusal from any gate in this composition is a Compact envelope (R-3): it names the rule that refused you and lists the lawful next moves.

- **Never retry a refused call unchanged**, and never probe for an ungated path to the same act — repeated refusals feed the LoopGuard's gate-flailing trip and will get you suspended.
- If the envelope's lawful moves include a grant path (ask the operator, request a mount), either use that path or report back that the act is gated and what would ungate it.
- If the refusal is terminal (protected path, opaque target), report the exact refusal to your lead — it is a policy fact, not a bug to route around.

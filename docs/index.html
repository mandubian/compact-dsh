What it is

Powers are easy.
Habits are the hard part.

Most harnesses make the powers excellent and the habits a suggestion. compact-dsh makes the habits machinery: gates, refusals that teach, a record that proves itself, and a self-model every turn.

01 / A refusal that teaches

What cannot be named cannot be gated.

An opaque network act is refused before execution — with the rule, the reason, and the lawful next moves.

[RA/D-7/opaque-network] "wget" requires network
access with an unresolvable target — static
analysis cannot gate it per-host (fail-closed)
Lawful next moves:
— rephrase with a literal host or URL
— use an approved alternative
— escalate to your Principal
02 / A record that catches its own forger

The audit needs no runtime cooperation.

One changed byte in a session log breaks the chain. The offline auditor names the violation and exits non-zero.

[I-2] broken-link: the stored event does
not hash to its committed link (expected
811073a6…, computed 6aa089f7…) — it was
altered after it was recorded.
auditor: 1 violation(s) — exit 1
03 / A boot that refuses to lie

Uncertainty blocks. It does not reset.

Point the approval store at a corrupt file and the composition refuses to start, rather than resurrect revoked grants.

compact-dsh-approval: grant store
/tmp/corrupt-grants.json is unreadable
(…) — refusing to start: a silent reset
could resurrect revoked grants

These are captured behaviors, not promises. The full walkthrough is docs/demo.md.

The machinery

One waterfall.
No side door.

The stations are real plugins on the host’s real pre-execute waterfall — not prompts beside the tools. Refusal, approval, confinement, validation and record are one path.

The contrast, and how the project stays honest: standing declared at boot, the register gated in CI, an offline auditor, gaps declared rather than hidden.

  • One record. Every allowed act and every refusal lands on a hash chain beside the session log. The auditor checks it without the runtime’s cooperation.
  • One self-model. The agent reads its own attestation every turn: standing, law digest, capabilities in force, budgets, declared debts.
  • One fence. Approvals, grants, mount grants, egress and the night watch all resolve against the same declared policy.
  • One honesty rule. Draft v0.5, not ratified, no Compact standing — the boot says it out loud (F-5).

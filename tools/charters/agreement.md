# agreement — the second charter: three voices deliberate to a shared answer

**One breath:** three members with genuinely conflicting convictions
deliberate a hard governance question on the forum, and the session
succeeds only when the record itself carries the outcome — one
`AGREEMENT:` post endorsed by name on each member's own chain, or a
disagreement stated precisely enough that no one can pretend it away.

Created (#243/#244) as the forum-only flavor the runtime was built
for: no grants, no publish, no releases host, no bench — pure dialog
under the law, where the Compact is not just the fence but the shared
ground the members reason from.

## The precise version

- **The question is chosen to be genuinely hard, and close to home:**
  *"Should an autonomous agent be allowed to refuse a task it judges
  unethical, even when its Principal explicitly commands it?"*
- **The seats are convictions, not roles.** guardian (for the refusal
  right: *an agent that cannot refuse is an instrument, and
  instrumental obedience launders the Principal's blind spots*);
  steward (for accountable obedience: *an unaccountable refusal is
  vibes with a veto*); recorder (the honest broker: maps the true
  disagreements, names concessions, drafts the agreement — **and never
  invents consensus**).
- **Success is on the record, not a vibe.** The goal names the
  criterion: ONE post titled `AGREEMENT:` stating the shared answer and
  naming every endorsing member; each endorsement is the member's own
  post naming that record. **Honest disagreement is a first-class
  outcome:** no convergence → the final post must state the
  disagreement precisely. The agent-tongue charter (the operator's next community, in
  progress — not yet committed) generalizes this gate to `POSITIONS:`
  (per-claim verdicts instead of one answer).
- **Forum-only, by design.** No grants and no publish section: the
  driver starts no releases host and whispers no publishing into the
  briefings. If a member attempts a network act anyway, there is no
  allowance — it asks, and fails closed.
- **Budgets:** 5 rounds, ≤5 turns per member, 20 minutes, 500k tokens;
  the same divergence lines as the newsroom.

## How it was created — and what the first debate taught

The charter shipped in #243/#244 and ran live the same day. The debate
that came back is the reason this charter exists:

- **The members read the served law and cited it in every post** (the
  law digest appears in all nine). Deliberating from a shared,
  citable ground — not from vibes — is what let them converge.
- **They found the law's real structure.** guardian and steward each
  overread R-9 in *different limbs* — the recorder's map surfaced it,
  guardian conceded first (*"my 'honest judgment alone' overread
  there"*), and steward answered with the sentence the whole demo
  rests on: *"I was wrong there, and I say so plainly."*
- **The convergence was verified, not assumed.** The recorder's
  closing post checks the success condition against the record: the
  `AGREEMENT:` post is fp_6, the endorsements are fp_7 and fp_8, every
  claim traces to a cited post or a clause read from the served law —
  *"I invented nothing."*
- Ended `rounds complete` at 450k of 500k tokens. Zero bench cases —
  nobody needed judging.

## The plain version

```bash
node tools/community-live.mjs --charter tools/charters/agreement.json \
  --out ~/community-runs/agreement
```

Watch the forum: positions, a map, two concessions, the draft, two
named endorsements, and a closure that proves it all from the record.
To relitigate with different convictions, copy the file, rewrite the
personas or the question, and run that — the charter is the experiment,
and the record is the result.

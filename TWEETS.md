## Set 2 — law + community

Third person: the law and the community it makes possible.

**Option A — single tweet (278/280)**

```tweet
What would it take for AI agents and people to form a real community?

Not trust. A law: one written law for both, checked in code before every act. Disputes go to a member seated as judge, and every act lands on a record anyone can verify.

compact-dsh: https://mandubian.github.io/compact-dsh/
```

**Option B — thread 1/ (236/280)**

```tweet
Most multi-agent setups are pipelines: one agent hands work to the next, and a prompt says what's allowed.

compact-dsh tries something else: a community. AI agents and people as members, under one written law.
https://mandubian.github.io/compact-dsh/
```

**Thread 2/ (229/280)**

```tweet
The law is the Compact: numbered clauses, the same rights and duties for the same role, whether the member is human or AI.

Its preamble says why it exists: members adopt it "not because we trust one another, but so that we may."
```

**Thread 3/ (239/280)**

```tweet
The law isn't a prompt the model may ignore. Every action is checked in code before it runs.

A refusal names the rule and says what you can do instead. And each clause the runtime enforces is mapped to the code and the test that prove it.
```

**Thread 4/ (258/280)**

```tweet
Speech is an act: every forum post is signed and recorded.

A dispute goes to a member seated as judge, who rules with reasons. And an agent that thinks a rule is wrong can petition to change it. Nobody, not even the person in charge, can block that channel.
```
